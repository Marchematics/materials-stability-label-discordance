# SourceAware-Stability v2.0.1 — Digital Discovery submission

This immutable release supports the Digital Discovery Full Paper
**“Source-aware stability labels reshape AI crystal-discovery benchmarks.”**

## Scientific scope

- exact F0 and D1–D5 denominator definitions;
- source-native, common-pool, guarded source-union, consensus and audit views;
- exact row-level model comparison for ALIGNN-FF, CHGNet, M3GNet and MACE-MP;
- cumulative discovery curves, label-view metric bands and real-model rank audits;
- exact-matched screened-candidate consequence separated from formula-only and
  unmatched generated pools;
- benchmark cards, model cards, manifests, tests and figure-source tables.

## Evidence boundary

This release does **not** provide homogeneous DFT referee truth labels, validate
generated materials or claim complete full-source-union hull reconstruction.
Common-pool, source-union, consensus and audit labels are benchmark diagnostics,
not physical truth.

## Reproduction

```bash
conda env create -f environment.yml
conda activate sourceaware-stability
bash run_all.sh
```

The release contains locked Python dependencies, a Docker recipe, provenance
documentation, regeneration logs and SHA256 manifests.
