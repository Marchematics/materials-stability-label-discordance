# M1 model-evaluation tables

These tables record the model-energy and predicted-hull construction used in v2.0.2–v2.0.3, including the 31,872-row common-support comparison. Files include scores, fixed-support metrics, validation-budget counts, elemental references and paired bootstrap summaries.

The current evaluation is in [`../referee_revision_v3/`](../referee_revision_v3/). It uses 36,650 compounds and excludes each target's structural-equivalence class from the reference hull used to score that target.
